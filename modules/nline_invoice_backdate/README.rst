##############################
N-Line Invoice Backdate Module
##############################

The *N-Line Invoice Backdate Module* allows a customer invoice to be dated
before an invoice already numbered in the same sequence, as N-Line does in
QuickBooks: 142 of the last 230 invoices, 94 of them within the same month, so
monthly sequences would not be enough.

The numbers stay sequential without gaps, so the number order may differ from
the date order. Posting into a closed period is still refused.
